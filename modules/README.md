# Módulos de Moody

Moody permite ampliar las fuentes y la apariencia mediante módulos. El catálogo integrado está en [`catalog.json`](catalog.json); los módulos de código propio se mantienen en el repositorio, como Spotify, Apple Music, JioSaavn y Monochrome.

Los módulos externos compatibles se agregan desde **Ajustes → Módulos → Añadir un módulo** pegando el enlace a un lanzamiento de GitHub que incluya un paquete válido. Revisa su código y procedencia antes de instalarlo.

Las interfaces y nombres de archivo históricos del formato de módulos se conservan por compatibilidad.
