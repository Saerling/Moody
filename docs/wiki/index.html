Módulos de Moody

Los módulos amplían las fuentes de música y la apariencia de Moody. Los módulos integrados se mantienen en este repositorio; puedes consultar el catálogo.

Instalar un módulo

En la aplicación, abre Ajustes → Módulos → Añadir un módulo y pega el enlace a un lanzamiento de GitHub compatible. Comprueba la procedencia del módulo antes de instalarlo.

Consulta la guía de módulos y el código del proyecto en Saerling/moody.
