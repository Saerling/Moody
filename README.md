# Moody

Reproductor de música para Android basado en Mochy Music de realidkroo (GPL-3.0). Moody reúne reproducción en línea y local, biblioteca, letras y módulos para ampliar sus fuentes.

## Compilar

Abre el proyecto con Android Studio o ejecuta `./gradlew assembleUniversalGmsDebug`. La app usa el identificador `com.saerling.moody`.
