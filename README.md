# Moody

Reproductor de música para Android con fuentes en línea y locales, biblioteca, letras y módulos para ampliar sus funciones.

## Compilar

Abre el proyecto con Android Studio o ejecuta `./gradlew assembleUniversalGmsDebug`. El CI compila y publica los artefactos.
